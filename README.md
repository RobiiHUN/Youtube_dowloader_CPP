## 📖 About

**Youtube_dowloader_CPP** is a lightweight C++ wrapper/utility that leverages `yt-dlp` to allow **YouTube video and audio downloads** from the terminal. It provides a minimal interface with fast execution and is written in modern C++.

---

## 🚀 Features

✔️ Download YouTube videos and audio via `yt-dlp`  
✔️ C++17-based native command-line interface  
✔️ Clean, simple code structure  
✔️ Ideal for learning process handling in C++

---

## ⚙️ Requirements

- 🧠 Basic C++17 support (tested with g++)
- 🧰 `yt-dlp` installed and available in system PATH
- 💻 Linux, macOS or Windows with command line

---

## 🔧 Installation

```bash
# Clone the repository
git clone https://github.com/RobiiHUN/Youtube_dowloader_CPP

# Navigate into the folder
cd Youtube_dowloader_CPP

# Compile (Linux/macOS example)
g++ main.cpp -o yt_downloader

```
